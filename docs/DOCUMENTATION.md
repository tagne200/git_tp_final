# Documentation — TP final de Git

## 1. Objectif

Ce dépôt est un exercice pédagogique. Il permet de pratiquer le fork, le travail à plusieurs, les branches et la fusion sur GitHub.

## 2. Contenu

| Fichier | Rôle |
|---|---|
| `README.md` | Énoncé du TP |
| `fork.md` | Procédure pour forker un dépôt |
| `add_collaborators.md` | Procédure pour ajouter des collaborateurs |
| `index.html` | Page utilisée pour les exercices |
| `styles.css` | Styles de la page |

## 3. Déroulement du TP

1. **Exercice 1 :** forker le dépôt et ajouter les collaborateurs.
2. **Exercice 2 :** présenter l'équipe dans le README et pousser le résultat.
3. **Exercice 3 :** travailler en équipe.
4. **Exercice 4 :** réaliser la fusion.

Le détail et le barème se trouvent dans le [README](../README.md).

## 4. Branches

| Branche | Rôle |
|---|---|
| `master` | Branche principale |
| `feature/collab-1` | Branche de collaboration 1 |
| `feature/collab-2` | Branche de collaboration 2 |
| `feature/collab-3` | Branche de collaboration 3 |

## 5. Consulter le projet

```bash
git clone https://github.com/tagne200/git_tp_final.git
cd git_tp_final
git branch -a
```

Ouvrez ensuite `index.html` dans un navigateur. Aucune installation n'est nécessaire.
